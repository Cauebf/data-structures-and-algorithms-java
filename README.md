## 🌐 Overview

**Data Structures and Algorithms in Java** is a collection of implementations and examples created to study fundamental data structures and algorithms using Java.

The repository focuses on understanding how different data structures work internally, how algorithms operate, and how their performance can be analyzed and compared.

Each topic is organized into its own directory, with Java source files containing the corresponding implementations and examples.

This repository is primarily a personal study project, created to practice Java programming and strengthen my understanding of data structures and algorithms through hands-on implementations.


## 📚 Topics Covered

The repository currently includes the following topics:

- 📦 **Stacks** — LIFO (Last In, First Out) data structure and its use cases.
- 🚶 **Queues** — FIFO (First In, First Out) data structure and its applications.
- ⭐ **Priority Queues** — Queue structures where elements are processed according to priority.
- 🔗 **Linked Lists** — Node-based linear data structures and their operations.
- 📐 **Dynamic Arrays** — Resizable array implementation and behavior.
- ⚖️ **Linked Lists vs Dynamic Arrays** — Comparison of their characteristics, performance, and use cases.
- 🔎 **Linear Search** — Sequential search through a collection.
- 🔍 **Binary Search** — Efficient searching in sorted collections.
- 📈 **Interpolation Search** — Search algorithm optimized for uniformly distributed sorted data.
- 🫧 **Bubble Sort** — Simple comparison-based sorting algorithm.
- 🎯 **Selection Sort** — Sorting algorithm based on repeatedly selecting the minimum element.
- 🃏 **Insertion Sort** — Sorting algorithm that builds the sorted portion incrementally.
- ♻️ **Recursion** — Solving problems by breaking them down into smaller instances of the same problem.
- 🔀 **Merge Sort** — Divide-and-conquer sorting algorithm with predictable performance.
- ⚡ **Quick Sort** — Divide-and-conquer sorting algorithm based on partitioning.
- #️⃣ **Hash Tables** — Key-value data structure using hashing for efficient lookup.
- 🧩 **Adjacency Matrix** — Graph representation using a matrix.
- 🕸️ **Adjacency List** — Graph representation using lists of neighboring vertices.
- 🌊 **Depth-First Search (DFS)** — Graph traversal algorithm that explores as far as possible along each branch.
- 🌐 **Breadth-First Search (BFS)** — Graph traversal algorithm that explores vertices level by level.
- 🌳 **Binary Search Tree (BST)** — Tree-based data structure for efficiently organizing and searching ordered data.

## 🚀 How to Run the Project

### ✅ Requirements

Before you begin, ensure you have:

- Java JDK 8 or higher
- Git installed
- A Java-compatible IDE or code editor (optional)

### ▶️ Running the Examples

1. **Clone the repository**:

    ```bash
    git clone https://github.com/Cauebf/data-structures-and-algorithms-java.git
    cd data-structures-and-algorithms-java
    ```

2. **Navigate to the desired topic directory**.

    For example:

    ```bash
    cd 01-stacks
    ```

3. **Compile the Java file**:

    ```bash
    javac Stacks.java
    ```

4. **Run the compiled program**:

    ```bash
    java Stacks
    ```

For another topic, simply navigate to its directory and compile the corresponding Java class.

For example:

```bash
cd ../08-binary-search
javac BinarySearch.java
java BinarySearch
```

> 💡 **Tip**: Some topics contain multiple .java files. In these cases, compile all required files together or run the project through your preferred Java IDE.
